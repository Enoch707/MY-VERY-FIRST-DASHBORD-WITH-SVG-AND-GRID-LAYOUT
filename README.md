# Vanilla CSS CRM Dashboard

A complex, fully responsive CRM dashboard built entirely from scratch using only vanilla HTML5 and CSS3. 

This project was built to master advanced CSS architecture, layout modules, and styling logic without relying on JavaScript or external CSS frameworks. It serves as a personal milestone in front-end development before transitioning into JavaScript-driven applications.

## ✨ Key Features & Technical Highlights

* **Advanced Layouts:** Utilizes a combination of **CSS Grid** (`grid-template-areas`) and **Flexbox** for a robust, multi-panel dashboard architecture.
* **Responsive Design:** Fully mobile-responsive layout using `@media` queries to adapt the grid for smaller viewports seamlessly.
* **No-JS State Management:** Implements the advanced CSS "Checkbox Hack" (`:checked ~`) to manage DOM states, including a functioning mobile hamburger menu and collapsible navigation dropdowns without a single line of JavaScript.
* **Pure CSS Data Visualization:**
  * Created a complex Donut Chart using modern `conic-gradient` and `mask: radial-gradient` techniques.
  * Designed scalable Line and Bar Charts using inline HTML `<svg>` paths and styled via CSS classes for crisp, responsive graphics.
* **Custom Styling:** Granular control over UI aesthetics using CSS custom properties (`:root` variables) for consistent theming and gradients.

## 🛠️ Tech Stack
* **HTML5:** Semantic structure and inline SVGs for charting.
* **CSS3:** Grid, Flexbox, variables, pseudo-classes, and advanced gradients. 

## 📂 File Structure
* `index.html` - The main structure of the dashboard and inline SVG charts.
* `style.css` - All styling, grid layouts, responsive queries, and state management logic.
